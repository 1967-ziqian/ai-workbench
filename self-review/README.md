# 复盘（self-review）

错题与措施台账，与方法库双向联动：复盘条目可一键跳到方法库对应方法，方法库可标记「回流自」复盘原条目（仅一层，防连环跳）。

## 结构

- `错题册.md` 模板：h2 领域 / h3 子域 / h4 条目。h4 格式 `#### 名称｜C-00X｜复发 N｜状态：待验证/已验证/已挂载`
- 状态机：待验证 → 已验证 / 已挂载

## 怎么用

- 在 `错题册.md` 按模板记坑，标 `C-00X` 稳定 id；
- 与方法库联动：复盘条目标「→库」指向方法库条目，方法库条目「回流自 C-00X」指回（见 `../shell/` 的 JumpBus 实现）。
