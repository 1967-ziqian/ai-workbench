# 插件安装安全闸门（硬规则，无一例外）

> **这条是用户定的铁律：以后引入任何外部代码/仓库/文件，都必须先过安全检查，不管是我（WB）还是 DSH 还是任何 AI。**
> "引入了再补审" = 不允许。先审后引，审不过就不引。
> **触发面不止"安装"**：`git clone` 一个仓库、`curl/wget` 下载一个文件、从外部介质复制一份代码——只要来源在本机之外、内容未经审，落地前都要过本闸门。纯文档仓也要过（markdown 里能藏"执行/删除/上传"类的提示注入，且可能带可执行样例）。

## 顺序

### 0 · 判类型
引入的是哪类：外部仓库（clone） / 下载的单文件 / DSH 插件 / WorkBuddy skill / npm 包 / MCP server / 可执行程序。
不同类型的攻击面不同：外部仓库能带 README 注入+隐藏脚本；npm 包进依赖链；DSH 插件能拿完整上下文+可能 spawn；skill 是 prompt 代码混合体。

### 1 · 验来源（可追溯性）
- 作者=仓库必须对得上，**引用仓库必须给能返 200 的 URL**，拿不到就写"未核实"（DS 2026-10-29 认错教训：搜索摘要里的仓库名当过事实）
- 同名/近名仓库先辨真伪（撞名仿冒：dsh-video-vision 仿冒案）
- 有没有官方市场？**无审核市场（"十大必装"类）不作为安装源**

### 2 · 下载不安装，先审代码
- npm 包用 `npm pack`（只下载不执行安装脚本）；GitHub 用 tarball 解压
- **grep 八词**（命中≠必拒，但要逐个翻那段代码在干什么）：
  `child_process` / `spawn` / `exec(` / `fetch(` / `.ssh` / `credential` / `process.env` / `eval(`
- 配置类文件额外查 `!!js`（YAML js-function 投毒：加载期执行，沙箱未初始化）
- **非 localhost 的 http 外联**单独列出来：外联到哪个域名、为什么、传什么
- 依赖链 `npm ls`：功能简单却拖几十上百包=不正常；拼写接近知名包（多一个字母）=高度可疑

### 3 · 判权限（一票否决项）
- **运行时注入器 / 要求 danger-full-access / 含 subprocess.spawn 的预设 → 默认不装**
- 除非用户**显式接受**"AI 可在本机执行命令"，且只装不需要升权的那部分（功能与权限能拆就拆）
- 判据不是"含 subprocess.spawn"，而是"**是否要求声明 sandboxMode 升权**"

### 4 · 结论落盘
- 装/不装 + 理由，写进当次会话输出和 `进度/` 对应页面
- 参考案例：routing-suite 审计（来源真、代码净、但权限高 → 交用户拍板）；video-storyboard（能力为零收益+有仿冒 → 不装）

### 5 · 装后 24h 加密监控（DS 定的频率）
- 常态：逃逸特征扫描每天 1 次（`tools/dsh_sec_check.py`）
- **装了新插件后 24h 内：加密频率（每 10 分钟），一周后回落**
- 分级不阻断：命中只记录+通知，不自动杀进程（误杀代价 > 漏报）
- 结果必须落盘可 diff（只打印=没跑）

## 执行约定（让闸门可被看见，不只靠记忆）

- **动作点前置输出 + 停在许可**（2026-10-29 晚上二次修；病灶：上一版只写"输出一行，再动手"，等于允许 AI 自审自批，当天因此连犯两次）：
  每次要 `git clone` / 下载 / 复制外部 / 装任何东西之前，先在本轮回复里输出一行
  `🔒 闸门预检｜类型=X｜来源=URL｜计划动作=…｜结论=过/不过｜许可=未获`，
  然后 **停手，等用户一句明确许可**；拿到许可才改写成 `许可=已获` 再动手。
  **这行不是"可以动手"的凭证，它只是一份申请书。没等到许可 = 不做，一个字节都不写。**
- **意图不推定**（同一天第二次失守的病灶）：用户发来**链接 / 视频 / 仓库** = 授权我**读**，不授权我**装、改、引入**。
  要装必须单独问一句"要不要装"，他说装才装。把"看一下这个"读成"装这个"就是越权。
- **来源拿不到可返 200 的 URL = 写"未核实"，不引**。
- 用户说"这个跳过检查" → 提醒一句铁律，他坚持则照办但**必须**在回复里留痕"用户豁免：…"。

## 失效信号

- 官方框架发布安全修复版本 → 重新审已装插件
- 本机出现来历不明的 `~/.dsh` 新目录/新工具名 → 立即跑体检
- 用户说"这个跳过检查" → 提醒一句铁律，他坚持则照办但留痕
