# 智慧提问法（L1–L5 漏斗）

## 一句话
**先把问题问清楚，再谈答案。** 漏斗的每一层只做一件事：把上一层的模糊变成下一层的可执行。

## 顺序

| 层 | 做什么 | 输出 |
|---|---|---|
| **L1 · 澄清意图** | 问清这件事到底要什么、要给谁、要什么形态 | 一句话目标 |
| **L2 · 补背景** | 补齐约束、已有材料、边界条件 | 背景清单 |
| **L3 · 定判据** | 事先说清"什么算做成"，避免事后自我感觉良好 | 判据/质量门 |
| **L4 · 生成方案** | 按 L1–L3 产出可执行提示词 | 提示词 |
| **L5 · 质量门** | 按 L3 的判据自检，不达标就退回对应层重来 | 通过/退回 |

## 判断点
- L1 问完还是说不清要什么 → **别往下走**，回 L1 换问法（要示例、要反例）。
- L3 的判据写不出来 → 说明目标本身没定住，回 L1。
- L5 不通过 → **退回对应层**（缺背景回 L2，方案糙回 L4），不要在 L5 硬修。
- 中途发现用户其实要的不是这个 → 回 L1，别在 L4 闷头做。

## 失效信号
- 跳过 L3 直接出方案 → 做完不知道算不算好，必然返工。
- L5 流于形式（"看起来还行"）→ 判据没落到可检验。
- 五层全做完但用户仍不满意 → 问题多半不在提示词，在 L1 问错了方向。

## 上游输入 / 下游输出
- 上游：一句模糊需求。
- 下游：一份可执行提示词 + 一套事先定好的判据（判据在执行阶段还要用，别丢）。
