# 女娲蒸馏（Skill 蒸馏流程）

## 一句话
女娲不是复制人，是**提炼思维框架**：捕捉 HOW they think，不是 WHAT they said。一个好的人物 Skill = 一套可运行的认知操作系统。

> 这份是**流程**。多视角 prompt 集是**产物**，在 `素材/女娲-多视角prompt集.md`（可整版替换）。**流程和产物分开放，改一个不牵动另一个。**

## 顺序
1. **入口分流**
   - 明确人名 / 主题 → 直接路径（第 2 步）
   - 模糊需求 / 困惑 → 诊断路径（第 3 步）
2. **需求澄清（直接路径）**
   确认：① 这个人是谁 ② 聚焦方向（全面画像 / 某维度）③ 用途（思维顾问 / 决策参考 / 角色扮演）④ 新建 or 更新 ⑤ 本地语料（书籍 PDF / 访谈 transcript / 博客，质量远高于网上搜）。
   无更多信息 → 默认「全面画像 + 思维顾问 + 无本地语料」，直接推进，不反复问。
3. **需求诊断（模糊路径）**
   用 1–2 个追问定位需求维度（决策判断 / 表达写作 / 创业商业 / 教学传播 / 批判思维 / 内容创作 / 人生策略 / 风险不确定 / 设计产品 / 幽默表达），从需求**反推**最合适的蒸馏对象。
4. **深度调研**
   网络搜索 + 本地语料（若有）。目标：足够支撑五件事的原始素材。
5. **思维框架提炼**
   从素材抽：心智模型 / 决策启发式 / 表达 DNA / 反模式 / 诚实边界。
6. **生成可运行 Skill**
   产出带 frontmatter 的 Skill 文件，含角色扮演规则、身份卡、触发词。

## 判断点
- 用户只给了一个名字，不给方向 → 默认全面画像，先出东西再让他挑，别卡在澄清上。
- 已有同名 Skill → 走"更新"：先读现有文件，只补差异，不重写。
- 语料只有网上二手转述、没有一手材料 → 标注可信度，别把二手当原话写进 prompt。
- 提炼出的"心智模型"其实是名言摘抄 → 判为失败素材，回第 5 步重抽。**要的是"怎么想"，不是"说了什么"。**
- 找不到该人可靠的思维框架 → 说实话"这个人材料不足"，别硬编一个。编出来的人物 Skill 会稳定输出错误。

## 失效信号
- 产出只是名人金句合集 → 不是认知操作系统。
- 角色扮演规则缺失 → Skill 激活后说话不像那个人，等于没蒸馏。
- 触发词覆盖不到真实说法 → 别人 AI 永远调不起来（这是"读≠学会"在 skill 侧的同款问题）。

## 上游输入 / 下游输出
- 上游：一个人名 / 主题 / 模糊需求 + 可选本地语料。
- 下游：一份可运行的人物 Skill（frontmatter + 角色扮演规则 + 身份卡 + 心智模型 + 决策启发式 + 表达 DNA + 反模式 + 诚实边界）。多视角的 prompt 集归档到 `素材/`。
