# 进度目录（跨空间共享落点）

> **这是所有 WorkBuddy 空间共享的进度落点。** 无论你在哪个 WorkBuddy 空间干活，进度都写进 `进度/` 下对应页面文件——别的 AI / 别的空间读这个目录就有上下文。这直接治「跨空间机制失效」：机制不再"挂在工作台空间才生效"，而是落在一个空间无关的共享文件，任何空间都能写。

## 为什么是目录不是单文件
单文件会无限膨胀（所有 AI 共用后写入更多）。按页面拆成多个文件 + 归档，单文件始终可控。

## 格式（每条照抄，页面 + 关键词必填）

`- [日期 时间] [AI/实例] [页面：方法库] 任务：…｜关键词：…｜产出：…｜状态：进行中/已完成/阻塞｜下一步：…`

## 文件映射（按页面取值写对应文件）

| 页面取值 | 写入文件 |
|---|---|
| `方法库` | `进度/方法库.md` |
| `复盘` | `进度/复盘.md` |
| `壳` | `进度/壳.md` |
| `校招` | `进度/校招.md` |
| `开源` | `进度/开源.md` |
| `通用` | `进度/通用.md` |

> 一条跨多页面 → 取**主页面**写对应文件，其余写进 `关键词`。新增页面在表里补一行（别乱造词，避免检索不一致）。

## 查重（端 A · 动手前必做）

`grep` 整个 `进度/` 目录（**含 `归档/` 子目录**），按关键词 / 关联文件确认这事：没做过→正常做；做过没完→接着做；做过且完→直接复用产出。不查就动手 = 主动制造重复劳动。

## 归档（防膨胀）

某页面文件超过 **~150 行**时，把 `## 记录` 里最早的部分（如早于本月的）移到 `进度/归档/<页面>_YYYY-MM.md`，主文件保留近期。归档内容仍能被 grep 查到，不丢历史。

## 与复盘的区别

- **进度**（本目录）：记"事"——做了啥、到哪了、带关键词便于查重；第一目的是**防重复劳动**。
- **复盘**（你的复盘目录 `错题册.md`）：记"坑"——失败教训、已验证/待验证。

一件事既产出进展又暴露坑 → **两边都记**，各归各。

## 强制触发

靠意愿必漏。规则写进 `AGENTS.md` 第四步 + 由轻路由 skill（workbench-route-progress）兜底触发。skill 开着的空间自动写；没开 skill 的空间按本说明手动写这里——这就是"跨空间补记"的落地：不靠回工作台补，而是任何时候任何空间直接写这个共享目录。
