# 进度

> **核心价值（先读这条）**：记进度第一目的**不是**"放索引"或"交接状态"，是**防重复劳动**——避免「明明做过的事，又因为没人记得、查不到，被重做一遍」。历史教训就是反复造轮子、重复消耗 token。本台账必须能被**动手前检索**才是真有用；只事后记、事前不查，等于没建。

## 一、为什么单独一块，不进方法库条目

目录 / 守则 / 身份是**静态框架**（一次写定、偶尔刷新）；进度是**动态记录**（每次任务追加）。两者性质不同，所以进度不进 `方法/` `自动化/` `素材/`，落单独的台账文件。

## 二、落点

`进度/`（按页面分文件的目录，见 `进度/README.md`）。这是**跨空间共享落点**：任何 WorkBuddy 空间的 AI 都读写这里，治 C-007「跨空间机制失效」。旧单文件 `工作台进度台账.md` 已迁至此。

**两层结构（2026-10-29 补）**：
- `进度/<页面>.md` = 情节层（哪天干了啥，带关键词查重）→ 治「重复劳动」；
- `进度/总览.md` = 语义层（各模块是干什么的、现状如何）→ 治「开新会话忘了已建能力」。
两层互补，不互相替代。总览只刷新、不追加；开局必读、收尾随改。

## 三、强制规则（靠意愿必漏，且必须两端都做）

光写进这份文档没用——必须落进 `AGENTS.md` 第四步 + 由轻路由 skill 兜底触发，才算"强制"。规则分**两端**，缺一不可：

### 端 A · 动手前查重（防重做的关键）
任何 AI 接到任务、**动手前先 grep 整个 `进度/` 目录（含 `归档/`）**（按任务关键词 / 关联文件），确认这事：
- **没做过** → 正常做；
- **做过但没完** → 接着做，不重做；
- **做过且完** → 直接复用产出，别再造一遍。
不查就动手 = 主动制造重复劳动。

### 端 B · 结束后记一笔
任务结束**向 `进度/` 下对应页面文件追加一条**（按「分类词表」页面取值选文件，映射见 `进度/README.md`）。不写等于这次工作没留痕，下个 AI 接手时两眼一抹黑，又会重做。**跨空间补记落地**：没开轻路由 skill 的空间（如其他 WorkBuddy 空间）也直接写这个共享目录，不用回工作台补。

每条字段：
- **日期时间**
- **哪个 AI / 实例**（区分不同 AI，避免混写）
- **页面 / 归类**：这条进度属于哪个工作台页面/组件（受控取值见下「分类词表」）。**必填**——按页面检索、不把不同块的进度混在一起，正是加这个字段的目的（跨空间/跨会话共用一本台账时尤其重要）
- **任务**：这次干了什么
- **关键词 / 关联**：便于检索去重的核心词 + 关联文件/方法（如 `方法库重组`、`renderMethodLib`）
- **产出物**：路径（文件 / 代码 / 文档）
- **状态**：进行中 / 已完成 / 阻塞（阻塞要写卡点）
- **下一步 / 待确认**：谁接、要什么

### 分类词表（页面取值，受控、可扩展）

记进度时 `页面：` 从下表取，没有就补一行（别乱造词，避免检索时词不一致）：

| 取值 | 覆盖什么 |
|---|---|
| `方法库` | 方法库条目、索引 `_INDEX`、框架/身份/GLOSSARY/AGENTS、回流进库的条目 |
| `复盘` | 错题册、体检、库回流、体检告警 |
| `壳` | luanyujia-shell 插件本身（渲染/启动/配置/selftest） |
| `校招` | 校招投递助手项目（DS 回信、探针、粤就业） |
| `开源` | GitHub 仓库、脱敏、README、开箱指南 |
| `通用` | 跨组件、S2 交接、诊断日志、协作纪律本身 |

> 一条进度若跨多页面，取**主页面**填 `页面：`，其余在 `关键词` 里点出（例如校招里做了方法库回流 → `页面：校招`，关键词带 `C-001回流`）。

## 四、与复盘的区别（别混）

- **进度**（本块）：记"事"——做了啥、到哪了、带关键词便于查重；第一目的是**防重复劳动**。
- **复盘**（`../self-review/错题册.md`）：记"坑"——失败教训、已验证/待验证。

一件事如果既产出进展又暴露坑，**两边都记**：进度记事（带关键词），复盘记坑，各归各。

## 五、为什么必须强制，不能靠自觉

历史教训：把"读索引""写留痕"当自觉动作，结果就是 AI 在简单任务、新会话、任务密集时全部跳过——然后同一件事被做第二遍、第三遍。凡是依赖 AI 自觉的动作，必须变成机制——文件写死规则 + skill/hook 兜底触发。本块规则和 `AGENTS.md` 第四步、轻路由 skill 三处同时锁，才不至于又变成"写下≠生效"。
