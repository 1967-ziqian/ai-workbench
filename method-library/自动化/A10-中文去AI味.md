# A10 中文去AI味

## 核心原则
**目标不是「写得好看」，是「写得不像AI」**——AI 检测抓的是统计特征（词频/句式/结构概率过高）。改的不是内容，是语言习惯。**保留原意只换皮**：观点/论据/引用全不动。**宁可粗糙不要工整**：人写东西有毛边，该停就停、该啰嗦就啰嗦、该没结论就没结论。

## 六大 AI 痕迹识别与改法
1. **意义膨胀**：产生了广泛影响/具有重要意义/深远的影响/系统分析了 → 降级为具体实在说法（「算是代表作」「挺关键的」）。
2. **三段排比**：政治上…思想上…文化上 / 为A服务为B服务为C服务 → 拆散，只留一两个。
3. **-ing 式假深度**：揭示了/呈现了/反映了/体现了/彰显了 → 删或换具体问句。
4. **模板式展开**：首先…其次…最后 / 本文将从三个方面展开 / 通过XX我们可以看到 → 换成随意组织（「下面说说」）。
5. **升华式结尾**：作为XX的学生我希望… / XX的价值在于… → 踩刹车，用具体事收尾。
6. **说教/鸡汤**：做学问就是要沉下心 / 这让我认识到XX的重要性 → 删，或换具体个人经历。

## 改写流程
1. **标记**：用六类扫全文，重点看段首段尾、排比、膨胀词、结尾两段。
2. **逐段改**（优先级）：结尾 → 段首段尾总结句 → 排比并列 → 膨胀词 → 模板展开。
3. **注入人味**：偶尔口语（算是/挺/蛮/说白了）、长短句不一、可单句成段、保留克制个人感受。
4. **自检**：哪段「太顺了」？结尾在升华吗？三个以上并列还有吗？

## Docx 处理
用 python-docx 读，只改文字不动格式（遍历 runs，清空前 n-1 个 run 的 text，新文字放最后一个 run）；输出 `_去AI味版.docx` 不覆盖原文件；原文件被占用自动换名。

## 注意事项
- **不改引用**（书名/人名/观点一字不动）、**不改数据**（事实/数字/年份）、**不过度改写**。
- 维普/微博主要抓词频分布和句式模板，不必改内容，只需打破统计特征。
- 实战：逯耀东《魏晋史学的思想与社会基础》读书报告，维普检测改后**零**，17处替换覆盖6类，保留全部观点。
