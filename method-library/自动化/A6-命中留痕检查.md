# A6 命中留痕检查

## 这条为什么存在
框架第 4 步要求任务首行留痕 `判据｜命中索引：…`。但**写这句是 AI 的输出，自动不了**；**检查它有没有写、写了有没有真读，可以由一条命令跑**。没有这个检查，"记下≠生效"——第三行判据就是装饰。

## 入口命令
```bash
python tools/recheck.py                  # 全量核查：打印 + 追加 复盘/体检.jsonl + 复查记录
python tools/recheck.py --last 20        # 只看最近 20 轮
python tools/recheck.py --dry-run        # 只打印「将生成 / 将跳过」，不落盘
python tools/recheck.py --rec PATH       # 换使用记录来源（fixture 用）
python tools/recheck.py --session PATH   # 换会话落盘来源（fixture 用）
```

## 输入
- 工作台会话落盘（被核查的轮次）。
- `复盘/使用记录.jsonl`（判断条目是否复发/漏提醒）。

## 输出
- `复盘/体检.jsonl`：体检记录。
- `复盘/使用记录.jsonl`：追加 `{"类型":"复查","条目":X}` 复查记录（带条目 id 关联）。
- 终端输出：`将生成复查：…` / `将跳过复查：…（原因）`。

## 退出码含义
- `recheck.py` 无显式退出码，成功返回 0；`--dry-run` 不写任何文件（末尾打印「[dry-run] 未落盘任何文件」）。

## 步骤
1. 扫最近 N 轮，认三类问题：
   - **该写没写**：一轮里写过文件 / 跑过命令 / 出现完成态断言，但输出里没有 `判据｜` 行 → 缺声明。
   - **假声明**：写了 `判据｜命中索引：X`（X 不是「无/不适用」），但同一轮里**没有读过任何 `复盘/` 下的文件** → 声明了命中却没读。
   - **完成态断言没带「怎么算成了」** → 断言无判据。
2. 「声明命中 X **且**真读了 X」这一事实本身 = 一次对 X 的**有效复查** → 追加复查记录，让「已验证（X 提醒 + Y 复查）」门槛可达。
3. **违例条目不生成复查**：join 使用记录，凡该条目有「是否复发=true」或「漏提醒=true」，命中轮不算有效复查——否则最该被验证的条目反而因最严重的一次失败而升「已验证」。
4. 按 (条目, 日期) 去重，同一条目一天只记一次复查，避免重跑虚高。
5. `--dry-run` 时打印**跳过原因**（复发/漏提醒 / 当日已有复查），不静默跳过。

## 验收
- `python tools/test_recheck.py` 全绿（正样本生成 + 负样本被拦 + dry-run 不落盘）。
- 真跑 `--dry-run` 后，`复盘/使用记录.jsonl` 前后一致（用 `cmp` 比对）。
