# A9 幕布大纲笔记

## 一句话原理
幕布是「缩进即层级」：按每行前导空格数判层级，**4 空格 = 1 级**，不认 Markdown 语法。AI 写的 `#` 标题/裸段落/表格粘进去层级会错乱（最典型：`#` 标题变成上一段正文的子级）。**全篇只用 `- ` + 4 空格缩进、不出现裸段落、不出现 `#`，层级永不乱。**

## 输出格式铁律
- 每一行以 `- ` 开头；层级由前导空格数决定，每深一级 +4 空格（顶层0/二层4/三层8/四层12）。
- **缩进单位必须统一**：全 4 空格或全 Tab，混用是错乱头号原因。
- **禁止**：`#` 标题、不带 `- ` 的裸段落、`**加粗**`/`*斜体*`、表格、代码块、`>` 引用、行内多空格对齐、手写 `1)` 混在 `- ` 里。
- 层级 ≤4；一节点一意；节点短（理想 ≤20 字）；中文全角标点、弯引号「」；除非要求不加 emoji。

## 三类笔记骨架
- **内容笔记**：来源 → 核心结论 → 展开论证 → 关键概念速查 → 我的行动。
- **日志笔记**（加分制，不写流水账）：事实(1-3件) → 感受(开心/充实/感谢) → 洞察(自己的) → 行为改进(继续/开始/停止)。
- **复盘笔记**：原定目标 → 实际结果(超预期/低于预期+原因) → 差异分析(客观/主观) → 下一步调整。

## 单源内容必加「边界与不适用」
笔记只来自一个人/一本书/一个 UP 主时，正文后必须加一节：语境与适用人群 / 不建议照做的 N 条 / 未经证实的个人判断 / 作者立场与利益 / 可交叉印证的部分。开头写清来源（标题/作者/时长/章节）。

## 从表达型内容抽知识（认知内核 + 传播税）
- 先判类型：知识型(抽机制与判据)/事件型(先补5W1R再谈意义)/观点型(抽论点标立场利益)。
- 认税：视频段子包袱、播客寒暄跑题、公众号标题党卖课、书铺陈注水、会议客套表态——**这一段删掉我的理解会变吗？不会=税，剥掉。**
- 四类留：定义/机制/判据/条件。
- 事件型铁律：事实与评价分开写；拿不准标【待核】；专名先核再写。

## 交付前自检（逐条过，不过就改）
1. 还有 `#` 吗 → 改 `- `。2. 有裸段落吗 → 挂 `- `。3. 缩进统一4空格吗（混2空格/Tab？）→ 统一。4. 有表格/加粗/代码块/`>` 吗 → 删或改。5. 层级>4吗 → 压。6. 节点只说一件事且够短吗 → 拆。7. 顶层是「主题+并列章节」吗。8. **文件名乱码**（实测 Write 中文名偶发 U+FFFD）→ 写完用 OS 接口打印复核。9. 表达型内容残留传播税吗。10. 案例都抽象成「例子结构」了吗。11. 事件型 5W1R 齐了吗。

**机检代替肉眼**：落盘后跑 `python scripts/check_mubu.py <笔记.md>`（查空行/行首/缩进4倍数/Tab/层级≤4/六类禁用/超长/文件名乱码，任一条不过退出码1）。

## 用户怎么用
全选复制 → 幕布 Ctrl+V（手机长按光标调粘贴菜单，别用输入法快捷粘贴）→ 点「思维导图」。错位了：大纲全选 Ctrl+Shift+F 自动格式化缩进。
