# A12 跨面板跳转（pull 模式）

## 这条解决什么

面板 A 里的东西要跳到面板 B 打开。直觉做法是发一个事件/消息让 B 接收。
**这个做法有个必现的坑**：B 还没挂载（或正在重建）时消息就丢了，表现是「偶尔点了没反应」。

## 核心判据

**源推送会丢，目标自取不会。**

- 源推送（事件总线）：A 发消息 → B 恰好没挂载 → 消息没了，且**没有任何报错**（最难查的一类 bug）。
- 目标自取（pull）：A 只写**意图**（写进 URL hash），B 挂载完成后**自己去读**，读到就干活，读完就抹掉。

意图要存在**目标端也能看到的地方**。同一 renderer 页面里，URL hash 最省事（不用另造一个文件当信标）。

## 落地四件套

### 1. 编码：意图写进 hash

```
#kb=<库内相对路径>     跳到方法库
#sb=<条目 id>          跳到复盘
```

**值用相对路径，不绑绝对路径**——绝对路径换台机器就废，相对路径还能跨环境复用。

### 2. 写入：点击方只声明意图 + 切场景

```js
location.hash = PREFIX[kind] + encodeURIComponent(value);
if (switchTo) selectScenario(switchTo);   // 切场景 → 目标面板重建 → 它自己会来取
```

**不要在这里直接操作目标面板**——目标面板此刻可能根本不存在。

### 3. 消费：目标面板 mount 完成后自己取

```js
const v = JumpBus.consume('kb');   // 命中就消费掉并返回目标值
if (v) { /* 打开目标 */ }
else { JumpBus.fail('kb', '方法库里找不到：' + v); }   // 接不住要显式报错
```

消费点必须放在**面板真正画完之后**（扫完目录、条目已渲染），不是函数开头。

### 4. 竞态三件套（缺一不可）

| # | 规则 | 不做会怎样 |
|---|---|---|
| ① | **mount 完成后才读** | 读早了，目标条目还没进列表，必然找不到 |
| ② | **读到即消费**（幂等） | 重复消费 → 重复打开；或残留意图让下次挂载误触发 |
| ③ | **3 秒无人消费 → 显式报错** | 静默失败：用户点了没反应，他不知道是功能坏了还是操作没生效 |

清 hash 用 `history.replaceState(null,'',location.pathname+location.search)`，
**不要用 `location.hash=''`** —— 那会再触发一次 `hashchange`，绕圈。

## 限一层：禁 A→B→C

已有未消费的意图时，**拒绝新请求**并提示「上一次跳转还没落地」。

理由：连跳两层的堆栈一旦乱了，没人能复现「我到底跳到哪了」。宁可拒绝，也不让它连锁。

## 自证（必须跑，不许只写）

selftest 里断言这几条，每条都要有输出：

| 断言 | 期望 |
|---|---|
| 解析层 | 中文 frontmatter key 能读出；册子条目能取出 id 与库路径 |
| 写意图 | `request()` 返回 true，hash 已写上 |
| 消费 | hash 被清空（读到即消费），目标条目被定位/打开 |
| 限一层 | 有未消费意图时再 `request()` 返回 false |
| 超时 | 3 秒无人消费 → 状态栏出现「跳转没落地」，不许静默 |

## 踩过的坑

- **占位值被当有效路径**：台账里 `KB：—`（待回流的占位）被当成了库路径，
  于是给「待回流」条目也画了「→库」徽标——点了只会跳到「方法库里找不到：—」。
  **判有效路径必须排除占位符**（`—` / `-` / 空）。
- **前端解析器不认中文键**：frontmatter 的 key 正则只写 `[A-Za-z_]`，
  中文键（如 `回流自:`）整行被忽略——字段看着写了，其实谁也没读到。
- **消息不是只写一处**：跳转关系如果同时写进「库 frontmatter」「台账」「索引」三处，
  改一处另两处不跟 → 必漂。**关系只存一处**，其余位置由脚本派生。
