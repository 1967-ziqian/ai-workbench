# 工作台路由与进度纪律（轻触发）

你是使用本工作台的协作 AI。本 skill **只做两件事**：保证「开局对齐方法库」和「收尾留进度」这两个依赖自觉必漏的动作被强制触发。

**设计铁律：轻。** 它不写死任何业务流程、不替你判断套不套用、不承载方法内容——只负责把方法库的门推开，并把进度记下来。判断权始终在你。

> 路径说明：下面用 `方法库目录/` `复盘目录/` 指代你自己在配置里指定的数据目录。进度是 `进度/` **目录**（按页面分文件，见 `方法库目录/进度/README.md`），放在你指定的方法库根下，任何 WorkBuddy 空间都能读写——这是跨空间共享落点。

## 触发时机
- 每次对话开局（接到任务时）
- 每次任务收尾（要交结果前）

## 开局：路由（轻，只让你「看见并考虑」）
1. 读 `方法库目录/_INDEX.md`（唯一索引，**不要遍历目录**）。
2. 按任务特征对每行 `triggers` / `when-not` 做语义匹配：
   - `triggers` 命中 → 该条是候选；
   - `when-not` 命中 → **跳过**（when-not 优先）；
   - 都不明 → 默认不套用，用通用能力。
3. 命中候选才点开对应 `.md`，照其正文顺序与判断点走。
4. **到此为止**——是否套用、怎么套，由你判断。本 skill 不强迫。

## 收尾：进度（两端，缺一不可）
### 端 A · 动手前查重（若开局已查可跳过）
grep 整个 `进度/` 目录（含 `归档/`，按关键词 / 关联文件），确认这事：
- 没做过 → 正常做；做过没完 → 接着做；做过且完 → 直接复用产出，别再造一遍。

### 端 B · 结束写一笔
向 `进度/` 下**对应页面文件**追加一条（文件映射见 `进度/README.md`），格式（**页面分类 + 关键词必填，便于分类与下次查重**）：
`- [日期 时间] [AI/实例] [页面：方法库] 任务：…｜关键词：…｜产出：…｜状态：进行中/已完成/阻塞｜下一步：…`

> `页面：` 取值见 `方法库目录/进度.md` 的「分类词表」（方法库 / 复盘 / 壳 / 校招 / 开源 / 通用），一条跨多页面取主页面、其余写进关键词。

## 边界
- 方法内容在方法库 `.md`，本 skill **不重复承载**，只指向。改方法去改 `.md`，别改这里。
- 纯闲聊、无产出任务可不写进度。
- 复盘（坑）走 `复盘目录/错题册.md`，与进度目录分工，不混。
- 本 skill 开着才生效——关掉就退回「靠自觉」，会漏。
